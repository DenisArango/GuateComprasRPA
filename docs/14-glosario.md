# 14 · Glosario

## Contratación pública

| Término | Definición |
|---|---|
| **Adenda** | Documento que modifica las bases de un concurso después de su publicación. |
| **Adjudicación** | Decisión de la junta que asigna el contrato a un oferente. |
| **Bases** | Documento que define las reglas del concurso: objeto, requisitos, criterios de calificación, plazos y garantías. |
| **Baja cuantía** | Modalidad de compra directa de montos menores, sin concurso. |
| **Compra directa** | Modalidad con oferta electrónica en Guatecompras, sin licitación ni cotización formal. |
| **Concurso** | Proceso competitivo de compra publicado en Guatecompras. |
| **Contrato abierto** | Catálogo de bienes con precios negociados del que las entidades compran directamente. |
| **Cotización** | Modalidad de compra para montos intermedios, con bases y junta. |
| **Desierto** | Concurso que termina sin adjudicación por falta de ofertas válidas. |
| **Fraccionamiento** | Dividir una compra en varias menores para evitar la modalidad que correspondería por el monto total. Está prohibido por la ley. |
| **Guatecompras** | Sistema de Información de Contrataciones y Adquisiciones del Estado de Guatemala. |
| **Inconformidad** | Objeción que un oferente presenta contra una decisión del proceso. |
| **Junta** | Comisión de la entidad que recibe, califica y adjudica las ofertas. |
| **Licitación pública** | Modalidad para montos mayores, con el procedimiento más formal. |
| **MINFIN** | Ministerio de Finanzas Públicas. |
| **MiPyme** | Micro, pequeña o mediana empresa. |
| **NOG** | Número de Operación Guatecompras; identificador único de un concurso. |
| **NPG** | Número de Publicación Guatecompras; identificador de compras sin concurso. |
| **OCDS** | Open Contracting Data Standard; estándar internacional de datos abiertos de contratación. |
| **OCID** | Identificador único de un proceso en OCDS. |
| **PAC** | Plan Anual de Compras de una entidad. |
| **RGAE** | Registro General de Adquisiciones del Estado; registro obligatorio de proveedores. |
| **Seguro de caución** | Garantía (fianza) exigida al oferente: de sostenimiento de oferta, cumplimiento, anticipo, calidad. |

## Técnicos

| Término | Definición |
|---|---|
| **ADR** | Architecture Decision Record; registro de una decisión técnica y su justificación. |
| **Automatización inteligente** | Combinación de RPA con inteligencia artificial para procesar información no estructurada. |
| **C4** | Modelo de diagramas de arquitectura en niveles: contexto, contenedores, componentes y código. |
| **Embedding** | Representación numérica de un texto que permite medir similitud semántica. |
| **ETL** | Extract, Transform, Load; proceso de carga de datos. |
| **Fixture** | Copia de datos o páginas usada para pruebas reproducibles. |
| **Hash (SHA-256)** | Huella digital de un archivo; dos archivos idénticos tienen el mismo hash. |
| **Headless** | Navegador que se ejecuta sin interfaz gráfica. |
| **LLM** | Large Language Model; modelo de lenguaje de inteligencia artificial. |
| **MoSCoW** | Técnica de priorización: Must, Should, Could, Won't. |
| **OCR** | Reconocimiento óptico de caracteres; convierte imágenes de texto en texto. |
| **Playwright** | Biblioteca de automatización de navegadores. |
| **REFramework** | Plantilla de UiPath para procesos RPA transaccionales robustos. |
| **RPA** | Robotic Process Automation; software que replica acciones humanas en interfaces de usuario. |
| **Selector** | Expresión que identifica un elemento en una página web. |
| **Zod** | Biblioteca de TypeScript para definir y validar esquemas de datos. |
